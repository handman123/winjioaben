# 需求文档：云电脑游戏数据持久化工具

## 1. 背景

用户租用云电脑玩 Windows 平台独占游戏（如《太吾绘卷》）。云电脑类似网吧环境，每次会话结束后系统会重置，所有用户数据丢失。用户已购买 5GB 个人数据盘，该数据盘与账号绑定，可在不同会话间持久化数据。

## 2. 核心功能

### 功能一：Steam 账号免密登录

- 备份 Steam 登录凭证（`loginusers.vdf`、`config.vdf`、注册表项）到数据盘
- 恢复时还原凭证，Steam 自动登录，无需重新扫码或输入密码
- 恢复前检测 Steam 是否运行，提示关闭

### 功能二：游戏存档备份

- **自动发现存档位置**：启动游戏后运行 `[D]`，脚本从游戏进程路径反查存档目录，无需手动配置
- 备份时压缩为 `.zip`，节省数据盘空间
- **存档轮转**：保留最近 5 份备份（FIFO），超出自动淘汰最旧的
- 支持多款游戏，通过 `games.json` 配置

### 功能三：游戏存档恢复

- 默认恢复最新备份
- 支持查看历史备份列表
- 支持从历史备份中挑选特定版本恢复
- 恢复前清理目标目录，确保干净状态

## 3. 非功能性需求

- **平台**：Windows 10/11，PowerShell 5.1
- **权限**：无需管理员权限
- **交互**：命令行菜单，双击 `.bat` 运行
- **编码兼容**：`.bat` 文件纯 ASCII，`.ps1` 文件 UTF-8 with BOM，解决中文 Windows GBK 编码兼容问题
- **容错**：数据盘未连接时明确提示；Steam/游戏未安装时跳过对应操作
- **可扩展**：通过 `games.json` 添加新游戏；核心逻辑 UI 分离，后续可做 GUI

## 4. 使用流程

```
首次使用:
  登录 Steam → [3] 备份凭证 → 启动游戏 → [D] 发现存档 → [5] 备份存档

日常使用:
  [2] 恢复全部 → 玩游戏 → [1] 备份全部
```

## 5. 数据盘目录结构

```
<盘符>:\GameDataKeeper\
├── .datadisk_id               # 标识文件
├── Steam\
│   ├── config\
│   │   ├── loginusers.vdf
│   │   └── config.vdf
│   └── registry.reg
└── Saves\
    └── {游戏}\
        └── {存档目录}\
            ├── 2026-07-07_143000.zip
            ├── 2026-07-07_120000.zip
            └── ...
```
